# ToDo Task Tracker

Simple project created with using React. This tracker allows user to create task and set priority for it. After that task will be displayed in scrollable container. 

Added tasks can be:
* Marked as "Done"
* Sorted to display only "Done" tasks
* Sorted to display active tasks
* Sorted by priority (descending)

There is also possiblity to toggle dark theme.

## INSTALL AND RUN

``` npm install ```

``` npm run dev```
